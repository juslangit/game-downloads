## Opening the games

- **macOS:** the games are not signed by Apple. The first time, right-click the app and choose **Open**, then **Open** again.
- **Windows:** if SmartScreen warns you, click **More info**, then **Run anyway**.
- **Android:** allow installs from unknown sources when your phone asks, then open the `.apk`.
